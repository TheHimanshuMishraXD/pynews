# NewsPulse

NewsPulse is a simple Python project that fetches the latest news based on the category selected by the user.

I built this project to practice working with APIs and understand how Python can fetch and process data from external sources.

## Features 🚀:

- Choose from different news categories.
- Get the latest headlines using NewsAPI.
- Display news titles and descriptions.
- Simple command-line interface.

## Categories 

- Technology
- Sports
- Business
- Entertainment
- Science

## Built With 🛠️:

- Python
- Requests
- NewsAPI

## How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd NewsPulse
   ```

3. Install the required library:

   ```bash
   pip install requests
   ```

4. Add your NewsAPI key to the application.

5. Run the program:

   ```bash
   python main.py
   ```
